# Cursed Dice

Небольшая аркадная игра на `Python` и `Arcade`. Игрок выбирает класс героя и дерется с волнами врагов.

## Что есть в игре

- три класса: воин, следопыт и волшебник;
- несколько волн врагов;
- ближние и дальние атаки;
- простые эффекты вроде оглушения, очарования и помехи;
- короткий и длинный отдых для лечения;
- таблица рекордов в файле `leaderboard.json`.

## Управление

- `WASD` или `стрелки` - движение;
- `левая кнопка мыши` - атака в сторону курсора;
- `Q` - короткий отдых;
- `E` - длинный отдых;
- `ESC` - пауза или выход назад в меню.

## Установка

Нужен Python 3.12.

```bash
pip install -r requirements.txt
```

## Запуск

Запускать лучше из папки проекта, потому что картинки подключены обычными относительными путями.

```bash
python main.py
```

## Зависимости

Главная библиотека - `arcade`. Еще используется `pillow` для простых текстур, которые рисуются прямо из кода.

## Текстуры

Все текстуры сгенерированы нейросетью `GPT Image`.
