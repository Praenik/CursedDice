# Cursed Dice

Небольшая аркадная survival-игра на `Python` и `Arcade` с боями в духе настольных RPG. Здесь нужно выбрать класс, пережить волны врагов и постараться закрыть забег как можно чище и быстрее.

## Что внутри

- Три игровых класса с разным темпом боя.
- Волны врагов, которые постепенно начинают давить сильнее.
- Ближние и дальние атаки, контроль и простые статус-эффекты.
- Короткий и длинный отдых прямо во время забега.
- Небольшая таблица результатов по времени и пройденной волне.

## Классы

- `Воин` — медленный, но надёжный боец ближнего боя с атакой по сектору.
- `Следопыт` — мобильный стрелок, который хорошо держит дистанцию.
- `Волшебник` — хрупкий маг с самонаводящимся огненным снарядом.

## Управление

- `WASD` или стрелки — движение.
- `ЛКМ` — атака в сторону курсора.
- `Q` — короткий отдых.
- `E` — длинный отдых.
- `ESC` — пауза или возврат назад.

## Противники

В игре есть несколько типов врагов: `Goblin`, `Worg`, `Nilbog`, `Hobgoblin` и `Bugbear`. У части врагов есть свои трюки: оглушение, помеха на следующую атаку, очарование или дополнительный урон, если игрок неудачно подставился.

## Запуск

```bash
pip install -r requirements.txt
python main.py
```

Если собираете релиз, можно использовать `build.ps1`.
