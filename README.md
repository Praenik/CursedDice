# Cursed Dice

`Cursed Dice` — небольшая аркадная survival-игра на `Python` и `Arcade` с боями в духе настольных RPG. Игрок выбирает класс, переживает волны врагов и использует характеристики, модификаторы и броски урона, вдохновленные D&D-подобной системой.

## Основные особенности

- Выбор из трех классов с разным стилем игры.
- Волновая структура боев с постепенным ростом сложности.
- Ближние и дальние атаки, эффекты контроля и особые способности врагов.
- Система короткого и длинного отдыха для восстановления здоровья.
- Отображение боевого фидбэка, таймеров эффектов и состояния персонажа прямо в бою.

## Классы

- `Воин` — крепкий боец ближнего боя с атакой по сектору перед собой.
- `Следопыт` — мобильный стрелок, атакующий одиночные цели с дистанции.
- `Волшебник` — дальнобойный маг, запускающий огненные снаряды.

## Управление

- `WASD` / стрелки — движение.
- `ЛКМ` — атака в сторону курсора.
- `Q` — короткий отдых.
- `E` — длинный отдых.
- `ESC` — выход в меню.

## Противники

В игре есть несколько типов врагов: `Goblin`, `Worg`, `Nilbog`, `Hobgoblin` и `Bugbear`. У части врагов есть особые механики, например оглушение, помеха следующей атаке, обаяние или дополнительный урон.

## Технологии

- `Python`
- `Arcade` — окно, рендеринг, спрайты, обработка ввода и физика простых столкновений
- `Pillow` — подготовка и загрузка текстур
- Объектно-ориентированная архитектура с разделением на `entities`, `views` и `core`

## Запуск

```bash
pip install -r requirements.txt
python main.py
```

Или запустить `exe` из релизов.

## Примечание по графике

Текстуры персонажей в проекте сгенерированы нейросетью и затем адаптированы для использования в игре.
